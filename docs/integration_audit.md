## Giải trình Entra ID trên GCP

Nhóm có thể dùng chung tenant, app registration và tài khoản demo đã chuẩn bị. OIDC xác minh token độc lập với hạ tầng hosting, phù hợp điều khoản cho phép provider khác khi có giải trình. SPA dùng Authorization Code + PKCE. API chỉ chấp nhận delegated access token v2 đúng tenant/audience/scope. Quyền album vẫn được xét trong API. Ghi Entra/JWKS là phụ thuộc ngoài vùng GCP, kiểm thử token đáo hạn và lỗi JWKS đã làm sạch. Workload GCP dùng IAM/ADC và Pub/Sub dùng Google OIDC riêng. [Google Cloud service identity](https://cloud.google.com/run/docs/securing/service-identity) · [Microsoft access token validation](https://learn.microsoft.com/en-us/entra/identity-platform/access-tokens#validate-tokens).
